About the Project

This project predicts the estimated price of residential properties in Bengaluru based on property characteristics such as total area, BHK, bathrooms, balcony, area type, and location.

🤖

How It Works

The entered property details are converted into the same feature format used during model training, scaled using the trained preprocessing pipeline, and passed to the trained Artificial Neural Network model to generate the estimated house price.
